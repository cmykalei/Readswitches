# Read Switches
COMPX203 Exercise 1: assembly programs for reading hardware switches.

## Project 🌳
```
.
├── ex1_q1.s
├── ex1_q2.s
└── ex1_q3.s
```

### Usage
Assemble and run each exercise on the lab machines using the course build environment.

## Commands
1. To assemble an exercise use the course assembler on `ex1_q<n>.s`.
2. To run use the course simulator or target hardware.
